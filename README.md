# The Dazzling Store

A responsive, multilingual storefront prototype for digital design files, including DXF downloads.

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Prototype features
- Responsive product gallery with search and category filters
- English, Arabic, French, Spanish and Chinese language selector
- Cart and wishlist interactions
- Seller upload form for a preview image and DXF file
- Demo checkout UI and proposed 20% platform commission

## Important limitations
This repository currently contains a **front-end prototype only**. It does not provide production accounts, a database, secure file storage, real payment processing, automatic seller payouts, or protected post-payment downloads. Upload selections and cart state are local to the browser. Do not collect real card details or rely on this prototype for live transactions.

Before accepting real customers, build and test a secure backend, authentication, private file storage, server-side order validation, payment-provider integration and webhooks, seller payout/commission logic, protected downloads, refund/dispute handling, privacy/terms and legal/tax compliance.

## Publishing with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Once deployment finishes, the site should be available at `https://ousxlk.github.io/the-dazzling-store/`.
